TRAIN-TEST SPLIT

test_size=0.2 means 80% train and 20% test. random_state makes the split

Do not use stratify for a continuous regression target.

Usually scales each feature to [0, 1].

IMPORTANT: Fit the scaler ONLY on training data. Use the fitted scaler
to transform test data and new samples.

SCIPY.STATS PROBABILITY DISTRIBUTIONS

from scipy.stats import norm, binom, poisson

Continuous normal distribution

dist = norm(loc=50, scale=10) # loc=mean, scale=standard deviation
dist.pdf(60) # Density at 60 dist.cdf(60) # P(X <= 60) dist.ppf(0.95) #
95th percentile dist.rvs(size=10) # Random samples dist.mean()
dist.var() dist.std()

P(40 <= X <= 60)

dist.cdf(60) - dist.cdf(40)

Discrete binomial distribution

b = binom(n=10, p=0.5) b.pmf(5) # P(X = 5) b.cdf(5) # P(X <= 5) b.sf(5)
# P(X > 5) b.ppf(0.95) b.rvs(size=10)

Common scipy.stats distributions: bernoulli, binom, poisson, geom,
nbinom, hypergeom, multinomial, uniform, norm, expon, gamma, beta, chi2,
t, f.

Discrete: use pmf(). Continuous: use pdf(). Continuous interval
probability: P(a <= X <= b) = cdf(b) - cdf(a).

============================================================ 9. EXAM
REMINDERS ============================================================

1.  Split data before fitting a scaler.
2.  Fit preprocessing only on training data.
3.  Transform test data and new samples using the already fitted scaler.
4.  X generally has shape (number_of_samples, number_of_features).
5.  Keras multiclass integer labels: Dense(number_of_classes,
    activation=“softmax”) loss=“sparse_categorical_crossentropy”
6.  Keras multiclass one-hot labels: Dense(number_of_classes,
    activation=“softmax”) loss=“categorical_crossentropy”
7.  Binary classification: Dense(1, activation=“sigmoid”)
    loss=“binary_crossentropy”
8.  Regression: Dense(1) with linear output loss=“mse”
9.  Convert probability rows to predicted class indices: y_pred =
    np.argmax(y_prob, axis=1)
10. StandardScaler is often useful for KNN, SVM, Logistic Regression,
    LDA/QDA and neural networks. Scaling is not compulsory for every
    model.
11. Linear Regression is primarily a regression algorithm. One-hot
    targets plus argmax adapt it for classification, but Logistic
    Regression is the standard classification method.
12. KL Divergence compares probability distributions; it is not a
    classifier.
13. For a continuous variable, PDF(x) is density, not P(X=x).
14. predict_proba() exists only for estimators that support
    probabilities.
